# Ledger Geeks

Software & blockchain/AI engineering studio site — static HTML/CSS/JS, no build step.

- `index.html` — homepage
- `consultation.html` — booking page
- `css/style.css`, `js/main.js` — shared styles/scripts
- `_archive-v1/` — earlier design iteration, kept for reference

## Run locally

```
python3 -m http.server 4200
```

Then open `http://localhost:4200`.
